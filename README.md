# 리텐션 하락 진단 — 가설 자동 생성

**결과 페이지 → <https://cwforest.github.io/retention-drop-page/>**

리텐션이 떨어졌을 때 **원인을 검증할 유저 집단 후보를 자동으로 찾아 순위를 매기는** 방법입니다.
KKBox 음악 스트리밍 로그로 만들고, **정답을 아는 하락을 직접 심어** 얼마나 작은 하락까지
잡아내는지 측정했습니다.

## 방법

1. **분석 테이블** — 행 하나 = 유저 한 명의 하루 (1,782만 행 · 유저 110만 · 설명 변수 23개)
2. **기대 모델** — 정상 기간에서만 학습해 "내일 돌아올 확률"을 냄. `편차 = 실제 − 기대`
3. **기준선 보정** — 집단마다 평소 추세를 직선으로 적합해 연장하고 뺌
4. **집단 탐색** — 조건을 최대 3개까지 붙여 가며 `t` 가 가장 음수인 집단을 찾음

산출물은 "원인"이 아니라 **먼저 검증할 가설 1~K위**입니다.

## 데이터

**원자료는 들어 있지 않습니다.**
[Kaggle WSDM Cup 2018 (KKBox)](https://www.kaggle.com/competitions/kkbox-churn-prediction-challenge/data)
데이터는 재배포가 금지되어 있어 직접 내려받아야 합니다.

`results/` 의 CSV 와 `web/data/` 의 JSON 은 전부 **집계된 결과**입니다.

## 주요 결과

- 조건 2개로 정의되는 정답 집단 15개를 **중앙 1.88%p** 하락까지 탐지 (평가 창 2일)
- 하한은 **유효 인원의 약 −1/3 제곱**으로 떨어짐 — 표본 오차만 작용한다면 −1/2 여야 함.
  기준선 오차에 바닥이 있기 때문이고, 그래서 **집단을 키우는 것보다 평가 창을 당기는 것**이 듣습니다
- 조건이 깊어질수록 병목이 "내 t 가 판정선에 닿느냐" 에서
  **"부모가 빔 20칸에 드느냐"** 로 옮겨감
